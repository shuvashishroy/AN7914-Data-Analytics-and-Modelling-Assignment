# AN7914: Data Analytics and Modelling

**Determinants of Interest Rates in the Consumer Credit Market**  
**Lending Club Dataset Analysis**

---

## 📋 Project Overview

This repository contains the complete submission for the **AN7914 Data Analytics and Modelling** summative assignment (University of Winchester, 2025/26).

The project investigates the key determinants of interest rates in peer-to-peer lending using a sample of **10,000 loans** from the Lending Club dataset.

### 🎯 Key Objectives
- Data preparation and cleaning (15 selected variables)
- Comprehensive Exploratory Data Analysis (EDA) with 7 visualizations
- Building and comparing five progressive OLS regression models
- Critical evaluation of the final full specification model (Model 5)

---

## 📁 Repository Contents

- **`AN7914_Assignment.ipynb`** — Main Jupyter Notebook (all code + outputs)
- **`loans_dataset.csv`** — Original dataset used for the analysis
- **`AN7914 Data Analytics and Modelling.pdf`** — Final report (with all figures, tables, and Harvard references)

---

## 🛠️ How to Run the Notebook

1. Clone or download this repository.
2. Ensure both files are in the **same folder**:
   - `AN7914_Assignment.ipynb`
   - `loans_dataset.csv`
3. Open the notebook in Jupyter Notebook, JupyterLab, or VS Code.
4. Run **Kernel → Restart & Run All**.

All charts, tables, and regression outputs are pre-rendered and saved in the notebook.
